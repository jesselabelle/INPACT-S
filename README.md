\# The Determinants of Cross-Border Patenting



Clean replication repository for the INPACT datasets and related results.



Structure (work in progress):



\- code/              Stata, SQL, and other scripts

\- data/raw/          PATSTAT and other raw extracts (not tracked in git)

\- data/external/     Small auxiliary datasets that can be redistributed

\- data/intermediate/ Generated intermediates (not tracked)

\- data/final/        Final public datasets

\- docs/              Documentation and notes
